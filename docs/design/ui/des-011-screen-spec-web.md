# DES-011 화면 명세서 (웹 UI)

> Phase 2: 웹 대시보드
> 문서코드: DES-011
> 버전: v1 (2026-09-01)
> 대상: 웹 UI 10개 화면 · 9개 모달/오버레이
> **원본**: [Notion DES-011](https://app.notion.com/p/3ced066504ec816b8b31cec6f3c4c56a) · Git 동기화 2026-09-02
> 기준 원본 정책: Notion = 대표 승인 원본 / Git = 에이전트 실행 원본. 충돌 시 Notion 우선.

## 목적

웹 대시보드의 모든 화면에 대해 **"어느 화면에서 어떤 버튼을 누르면 → 어디로 이동하거나 어떤 팝업이 뜨고 → 거기서 어떤 데이터를 보는가"**를 빠짐없이 정의한다.

## 범위 주의

Phase 1은 CLI 전용이며 웹 UI는 **Phase 2 범위**다. 이 문서는 Phase 2 착수 전 설계 선행분이며, Phase 2 기획(PLN) 확정 시 요구사항 매핑을 재검증해야 한다. Phase 1 CLI 명세는 [DES-006](des-006-screen-spec-cli.md)을 따른다.

### 4-2. 드로어

| 드로어 ID | 제목 | 호출 이벤트 | 표시 데이터 | 인터랙션 | 닫기 |

| **DRW-01** | 상태 이력 | EVT-P02-8, A02-10, T02-6 | 시각, From, To, 변경자 (최근 20건, 스크롤 시 추가 로드) | 행 클릭 → 해당 시점 상세 툴팁 | [×] / ESC / 바깥 클릭 |

### 4-3. 오버레이 공통 규칙

1. **닫기 경로 3종**을 모두 제공한다 — [×] 버튼, `ESC` 키, 바깥 영역 클릭.
2. 입력 중인 모달(MOD-01~03)은 바깥 클릭 시 **"작성 중인 내용이 사라집니다"** 확인을 거친다.
3. 파괴적 작업(MOD-05, MOD-06)은 **영향 범위를 건수와 목록으로** 먼저 보여주고, **확인 체크박스**를 통과해야 실행 버튼이 활성화된다.
4. 파괴적 모달의 기본 포커스는 **[취소]** 버튼에 둔다.
5. 모달 위에 모달을 띄우지 않는다. 연속 확인이 필요하면 단계형 모달(step)로 처리한다.
