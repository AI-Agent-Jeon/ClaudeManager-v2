## 요구사항 코드

요구사항의 분류와 고유 번호를 결합한 코드.

| 접두사 | 분류 | 설명 | 예시 |
|--------|------|------|------|
| FR | 기능 (Functional) | 시스템이 수행하는 기능 | FR-001 백엔드 서버 시작/종료 |
| NFR | 비기능 (Non-Functional) | 성능, 보안, 가용성 등 | NFR-001 API 응답 성능 |
| UIR | UI/UX | 화면 구성, 사용자 경험 | UIR-001 대시보드 레이아웃 |
| DAT | 데이터 (Data) | 저장, 스키마, 무결성 | DAT-001 SQLite 저장소 |
| INT | 인터페이스 (Interface) | 시스템 간 연동, 통신 | INT-001 CLI-백엔드 통신 |

### 번호 부여 규칙

- 분류별 독립 채번: FR-001, NFR-001은 서로 독립
- Phase 간 연속: Phase 1에서 FR-012까지 사용 시, Phase 2는 FR-013부터
- 삭제된 코드는 재사용하지 않음
- 한 스토리에 하나의 코드 (1:1 매핑)
